# Forage-ANZ-Cyber-Security-Management
ANZ virtual experience program on Forage.

Investigate suspicious emails and use open source tools to identify and investigate potential cybersecurity threats with ANZ.

## Task 1 - Social Engineering Investigation

### Scenario
A set of emails has been allocated for investigation. Each email must be analyzed to determine whether it is safe or malicious.

Malicious content may include:  
- Malicious attachments  
- Suspicious links  
- Phishing attempts designed to gather private account information  

Report findings on each email, detailing reasons for classifying it as malicious or confirming it as safe.

## Task 2 - Digital Investigation
### Scenario
Suspicious network activity has been detected coming from a user on the ANZ network. Investigate the network traffic in order to establish what the user accessed and downloaded.

The provided packet capture may contain multiple artifacts, such as:  
- Images viewed  
- Files accessed or downloaded  

Report findings of all artifacts identified.

### Tools Used
- Wireshark
- `xdd` command
- CyberChef
